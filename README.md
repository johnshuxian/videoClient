# 影窗

支持 Windows、macOS、Android 手机和平板及 Android TV 的视频客户端。

本仓库提供安装包、版本说明和自动构建流程，应用源码在私有仓库中维护。

## 下载

前往 [最新版本](https://github.com/johnshuxian/videoClient/releases/latest) 下载对应安装包。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `videoClient-vX.Y.Z-windows-x64.exe` |
| macOS ARM64（Apple Silicon） | `videoClient-vX.Y.Z-macos-arm64.dmg` |
| Android 手机和平板 | `videoClient-vX.Y.Z-android.apk` |
| Android TV | `videoClient-vX.Y.Z-android-tv.apk` |

Android 和 Android TV 最低支持 Android 8.0，两者可以同时安装。

## 更新

在应用设置页点击版本号检查更新。已有客户端的检查更新和下载地址保持不变。

## 功能

- 点播源管理、搜索和多集播放。
- 本地保存设置及播放记录。
- 桌面端支持 DLNA 投屏。
- Android TV 使用遥控器操作和原生播放器。

## macOS 首次运行

macOS 安装包使用 ad-hoc 签名，未经过 Apple 公证。如果系统阻止打开，可在“系统设置 → 隐私与安全性”中允许打开。

如需反馈问题，可在本仓库创建 [Issue](https://github.com/johnshuxian/videoClient/issues)。
